🔬 How Closed-Loop Evolutionary LLM-PCG Works
1. GENOTYPE
Parameter Vector G_N (Difficulty, Room Density, Traps, Corridor Width, Enemy AI Type).
2. PHENOTYPE
C++ PCG Generator compiles genome into 2D tile layout map & spatial spawns.
3. FITNESS (F)
Real-time telemetry collects Clear Speed, Damage, Retries, Kills & Exploration %.
4. MAP-ELITES MUTATION
MAP-Elites archive breeds G_{N+1} = G_N + ΔG via tournament selection & crossover.
⚡ Research Objective: Discovers human playstyles algorithmically using telemetry feedback vectors instead of predefined static game design rules. Every level mutates parameters dynamically to match your evolving skill curve.
